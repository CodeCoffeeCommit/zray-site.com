Sculpt at fifty million polygons. Then keep going.

ZRay is a modular creation platform for Windows. Sculpting, modeling, painting, texturing and simulation share one engine — and each one works on its own.

Get the preview build How it's built

One engine, separate tools

Each module is modeled on the best tool in its class. Install what you use; nothing else loads.

Sculpt

ZBrush-class organic sculpting. The viewport cost scales with screen pixels, not polygon count, so meshes past 50M stay responsive.

Model

Polygon modeling with a modifier stack, on a kernel that handles wires, fins and non-manifold geometry.

Paint & animate 2D

Raster and vector painting with layers, plus bone-based 2D animation.

Texture

Paint materials directly on the mesh, Substance-style.

Simulate

A live procedural node graph that is the object — Houdini-style effects and geometry.

CAD

Parametric objects that keep their own recipe and history.

Built as a kit, not an app

ZRay is a set of independent C++ libraries — UI, core, brush engine, layers, nodes, rigging — that depend downward only. Take one library into your own tool and you pay nothing for the rest. Any object can be converted between sculpt, editable mesh, parametric and procedural forms, and every attribute can be wired to any other, only when you ask for it.
